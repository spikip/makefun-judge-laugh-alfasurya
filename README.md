## About this entry

The line is an office joke about a trust-fall team building
exercise, and it works because everyone in an office has lived some
version of it. The setup is familiar, the fall happens, nobody
catches anyone, and then HR arrives with the perfect corporate
spin, calling the disaster a valuable lesson in self-reliance. That
last line is the turn: the failure is not denied, it is rebranded,
which is exactly how office language papers over embarrassment. The
observation is true to office life, the surprise is sharp, and the
line is tight enough to repeat at the next meeting. It stays well
inside the two hundred character cap. The program holds the line,
checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
